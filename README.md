# Handoff: MEGA KHUJAND — редизайн сайта ЖК

## Overview
Премиальный сайт жилого комплекса MEGA KHUJAND (Худжанд). Переход от тёмной «пустой» эстетики к тёплой светлой с сюжетной подачей. Пять экранов: главная (7 сцен скролла), каталог квартир, подбор на фасаде, страница квартиры, 3D-деталь фасада.

Исходный репозиторий: `hmakhsudov/mega-khujand` (branch `main`) — файлы `index.html`, `flats.html`, `building.html`.

## About the Design Files
Файлы в этом пакете — **дизайн-референсы в HTML**, а не продакшн-код. Задача — **воссоздать их в кодовой базе репозитория** (сейчас это статичные `index.html` / `flats.html` / `building.html`) её средствами. Если выбираете фреймворк заново — подойдёт Astro или Next.js со статическим экспортом.

Файлы `*.dc.html` — это «Design Components»: разметка с инлайн-стилями, шаблонные дырки `{{ … }}` и JS-класс `class Component extends DCLogic` внизу файла. Они открываются в браузере напрямую (нужен `support.js` рядом и локальный сервер, например `npx serve .`). Для переноса: берите разметку и стили как есть, логику из `renderVals()` переносите в обычный JS/компоненты.

## Fidelity
**High-fidelity.** Цвета, типографика, отступы, маски, анимации — финальные. Воссоздавать пиксель-в-пиксель.

## Screens
1. **Mega-Khujand-Home.dc.html** → `index.html`. 7 сцен со скроллом и пиннингом: герой (рендер `facade-night-hero.jpg` как маска заголовка, срок сдачи вместо кнопки видео), архитектура (со встроенной 3D-деталью фасада), «Панорама» `#mk-pano` (речная маска 66% → 100% с контр-масштабом), двор, сервисы (карусель), подбор на фасаде (встроен Picker через `?embed=1`), контакты. Плавающая навигация.
2. **Mega-Khujand-Flats.dc.html** → `flats.html`. Каталог: фильтры (комнатность, этаж, площадь, цена, статус), вид плитками и строками (flex, не `<table>`).
3. **Mega-Khujand-Building.dc.html** → `building.html`. Шахматка: корпус → секция → стояк → этаж; статусы; пентхаусы на верхнем этаже. Встроенный Picker.
4. **Mega-Khujand-Flat.dc.html** — детальная страница квартиры: планировка (SVG из `media/plans/`), характеристики, цена, CTA.
5. **Mega-Khujand-Picker.dc.html** — подбор на фасаде. Рендер как фон + SVG-полигоны (4 точки) по гомографии плоскостей фасада. Переключатель день/сумерки, фильтры, hover-подсказка, панель лота. Координаты откалиброваны по сетке окон — см. `calibration/cal-FINAL.json`. Правое крыло в сумеречном ракурсе убрано (штукатурка, не остекление). В сумеречном виде у подсветки усиленный `mix-blend-mode: multiply`.
6. **Facade-Detail-3D.html** + `three-d-stage.js` — three.js-деталь угла фасада: камень (процедурные normal/roughness), стекло с env-map, металлическое ограждение балкона. OrbitControls с ограничением азимута/высоты, без авто-вращения, кликабельные образцы материалов, экспорт OBJ/GLB.

## Interactions & Behavior
- Анимация привязана к скроллу через события scroll (без постоянного rAF-цикла). Анимируются кадры и маски; fade-up текста нет.
- Сигнатурные приёмы: раскрытие кадров органической «речной» маской; плавающий слой теней листвы на всех страницах.
- Точные длительности, кривые и пороги — в логических классах соответствующих `.dc.html`.

## Design Tokens
- Палитра: кремовый камень, песок, графит, бронза. Точные hex-значения — в инлайн-стилях DC-файлов (одни и те же литералы повторяются на всех страницах).
- Шрифты: **Prata** (заголовки), **Manrope** (текст/интерфейс), Google Fonts.
- Все цифры: `font-variant-numeric: lining-nums tabular-nums` (цены, площади, таблицы, поля ввода).
