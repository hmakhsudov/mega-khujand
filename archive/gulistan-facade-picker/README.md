# Архив: подбор квартир на фасаде (рендер Гулистона)

Убран с сайта 2026-10-28 по просьбе пользователя: фасад на этих рендерах — дом **Гулистон**, а сайт пока только про Сырдарью. Систему не удаляли — её вернут, когда на сайт добавят Гулистон.

## Что было на сайте

- `picker.html` — страница «Подбор на фасаде»: вечерний и дневной рендер, в окнах свободных квартир горит свет, наведение показывает этаж и квартиру.
- Главная, «Свободные квартиры» — фасад с огнями, табличка этажа «как в лифте», кнопки по комнатности (`.model` в `index.html`, код в `js/home.js`).
- Шахматка (`building.html`) — раздел «Та же шахматка на фасаде» со встроенным подбором (`picker.html?embed=1`).
- Карточка квартиры (`flat.html`, `js/flat.js`) — первый кадр галереи: окна этой квартиры на вечернем рендере.
- Ссылки «Подбор на фасаде» в подвале всех страниц и `picker.html` в `sitemap.xml`.

## Что лежит здесь

- `picker.html`, `js/picker.js` — страница подбора.
- `js/facade.js` — движок фасада: окна, этажи, свет, наведение (`MK.facade`).
- `js/facade-light.js` — слой света вечернего рендера (`MK_LIGHT`), генерирует `tools/facade-light.py`.

## Что осталось на месте

- Данные плоскостей фасада и окон — `FACADE`, `windowOf`, `lightKey` в `js/data.js` (на сайте сейчас не используются).
- Стили `.model`, `.pk`, `.embed`, `.lift`, `.gallery__win` — в `css/site.css`.
- Картинки: `media/opt/facade-*`, `media/light/`, исходники `media/renders/facade-*`.

## Как вернуть

Полная версия сайта с подбором сохранена в git под меткой `archive/gulistan-facade-picker`:

```bash
git checkout archive/gulistan-facade-picker -- picker.html js/picker.js js/facade.js js/facade-light.js tools/facade-light.py
```

Встройки на главной, в шахматке и на карточке квартиры — взять из той же метки (`git show archive/gulistan-facade-picker:index.html` и т. д.). Убрать перенаправление `/picker.html` из `_redirects`. Когда появятся рендеры Гулистона по его вкладке — перепривязать сетку окон (`tools/facade-light.py`) к ним.
