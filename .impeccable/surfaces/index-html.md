# MEGA KHUJAND — sales site, redesign «Выставочный макет»

## Scope and mode
Five static pages, plain HTML + css/site.css + vanilla JS, no build step. Replacement visual world (the user judged the cream / Prata / bronze build "AI-generic"); product truth, content, data and function stay. The 3D fragment is removed at the user's request (home section and facade-3d.html). The wordmark-mask hero stays; what follows the mask is rebuilt. No national ornament (user: cliché).
- `index.html` — Persuade. `flats.html`, `building.html`, `picker.html` — Operate. `flat.html` — Operate with a Persuade close.

## Audience, job, action
Local Khujand families first; returnees and local professionals on the same paths. Job: understand the project, find a specific flat, talk to a person. Action: lead form (name, +992 phone, call / WhatsApp / Telegram / showroom visit, optional lot), phone, messengers.

## Home order
Mask hero → lit model (available windows over the dusk render, bedroom keys, tag) → plans (ascending types, counts, price-from) → materials board keyed to the corner render → site legend (courtyard, playgrounds, arcade, embankment) → service directory → showroom close with the form.

## Direction contract
THESIS: The sales-office model under glass — a family leans over the vitrine while the manager lights up the free windows; the site does exactly that on the real night facade. Refuses full-bleed render + serif headline + pinned mood chapters, and the cream-serif-bronze "warm premium" default.
OWN-WORLD: Vitrine graphite #121416 rooms and plaster white #EEF0EE fields (the model and its base); warm LED #FFD58A only where a flat is available; brass #B08D57 as flat engraved plates, keys and tags — no gradients, no glows, no pills. Unbounded wide caps for plates and display, Manrope for reading and tabular numbers. Machined 3px corners, 1px engraved rules, numbered brass legend keys, keys with an LED dot for on/off state.
STORY: Through the name onto the model at dusk → the free windows light up floor by floor → press a key to light only 2-bedroom flats, tap a window for its tag → plan pieces with real counts and prices → materials and the site legend → the lobby directory of services → come to the showroom about a specific flat.
FIRST VIEWPORT: Plaster field with MEGA KHUJAND in heavy wide caps cut through it, the dusk render glowing inside the letters; below: h1 «Дом, который узнают по вечернему свету», one line, brass «Выбрать квартиру» + outline «Записаться на показ». Header: brand plate, four links, phone. Signature: from 900px scroll flies through the letters onto the dusk facade, available windows switch on bottom-up, the brass key console appears; motion is one scroll clock — veil, then light, then console; reading text never moves. Mobile and reduced motion: the same scenes stacked, no pin.
FORM: Showroom model (sales-office vitrine) — the top of my seven grounded candidates, taken by the user as IMPECCABLE'S PICK over the roll (technical passport); seed key d5e9e4aa.
